Política de Privacidade do JEV

Última atualização: 14 de outubro de 2026

O JEV é um assistente pessoal para Windows, de uso privado, instalado no computador do próprio usuário. Esta política explica quais dados o JEV acessa, como os usa e como o usuário pode revogar o acesso.

1. Quem é o responsável

O JEV é desenvolvido e usado por Rheverson Lino. Contato: revlino53@gmail.com.

2. Dados do Google que o JEV acessa

Somente depois que o usuário conecta a própria conta Google e autoriza na tela de consentimento do Google:

  • Gmail (gmail.modify): ler e buscar e-mails, criar rascunhos, marcar como lido/arquivar e enviar e-mails pedidos pelo usuário.
  • Google Agenda (calendar): listar compromissos, criar e cancelar eventos pedidos pelo usuário.
  • Google Drive (drive.readonly e drive.file): buscar e ler arquivos do usuário e criar documentos novos (por exemplo, atas no Google Docs).
  • Perfil básico (openid, email): identificar qual conta está conectada.

3. Como os dados são usados

  • Os dados são usados apenas para atender aos pedidos que o próprio usuário faz ao assistente (por exemplo, “o que tenho hoje?”, “resuma meus e-mails não lidos”, “responda que confirmo”).
  • Enviar e-mail, criar ou cancelar evento e criar documento sempre exigem a confirmação explícita do usuário.
  • Para entender o pedido e escrever a resposta, o trecho necessário (por exemplo, o assunto e o texto de um e-mail) é enviado à API de inteligência artificial da Anthropic (Claude), que processa o conteúdo apenas para gerar a resposta e não o usa para treinar modelos.
  • O JEV não vende, não aluga e não compartilha dados com terceiros para publicidade ou qualquer outro fim, e não usa os dados para criar perfis de anúncios.
  • Nenhuma pessoa além do próprio usuário lê os dados.

4. Armazenamento e segurança

  • O JEV funciona no computador do usuário. O acesso à conta Google (token de atualização) fica guardado no cofre de credenciais do Windows, nunca em arquivo de texto nem em servidores do JEV.
  • E-mails, eventos e arquivos são buscados no Google no momento do pedido e não são copiados para servidores próprios. Conversas com o assistente ficam no computador do usuário.
  • As comunicações com o Google e com a Anthropic são criptografadas (HTTPS).

5. Uso limitado (Google API Services User Data Policy)

O uso e a transferência, pelo JEV, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Como revogar o acesso e apagar os dados

  • No JEV: peça “desconecte meu Google”. O acesso é revogado no Google e apagado do cofre do Windows.
  • No Google: myaccount.google.com/permissions › JEV › Remover acesso.
  • Desinstalar o JEV apaga os dados locais.

7. Alterações

Mudanças nesta política serão publicadas nesta página, com a data de atualização.
